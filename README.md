## Featured project

### [AI Core Operating Protocol](https://github.com/mannod0327-oss/ai-core-operating-protocol)

One vendor-neutral operating skill designed to help AI agents select relevant available capabilities and check their work.

- **Cross-agent packaging:** layouts for Codex, Claude Code, Gemini CLI, Antigravity, Cursor, Copilot, OpenCode, and generic Agent Skills hosts.
- **Controlled installation:** plan, install, verify, and rollback with ownership checks and retained snapshots.
- **Verified builds:** automated checks across Windows, Linux, and macOS with Python 3.12 and 3.13.
- **Transparent scope:** prerelease packages with documented limitations; native host activation is not yet certified.
